# TranslateBar

Клиентский Fabric-мод для Minecraft Java. Две полупрозрачные кнопки прямо в полосе чата: `文` переводит текст из поля ввода одним кликом, кнопка с кодом языка (`EN`, `DE`, …) переключает язык назначения. Исходный язык определяется автоматически — можно печатать на русском, английском, японском, любом.

Поддерживаемые версии игры: **1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, 26.3** — для каждой линии свой файл.

> **English:** [README in English](README.en.md) · [page text (EN)](modrinth/description.md) · [текст страницы (RU)](modrinth/description.ru.md).

## Возможности

- Чёрные полупрозрачные кнопки в стиле строки чата: высота и положение совпадают с плашкой ввода, прозрачность подстраивается под настройку фона текста в игре.
- 10 языков перевода: английский, немецкий, французский, испанский, польский, китайский, русский, японский, итальянский, португальский.
- Подсказки и сообщения — на русском или английском, в зависимости от языка игры.
- Перевод подставляется в поле ввода, но не отправляется — проверяешь и жмёшь Enter.
- Команды (`/…`) и пустой ввод не переводятся.
- Запрос уходит в фоне — игра не подвешивается.
- Без API-ключей и конфигов.

## Установка

1. Fabric Loader и Fabric API под свою версию игры — в папку `mods`.
2. Скачать JAR TranslateBar под свою версию (см. «Сборка» ниже или файлы релиза) и положить туда же.
3. В игре: чат на `T` → ввёл текст → клик по `文`.

## Сборка

Нужен JDK 25 и Gradle. Все линии собираются из одного проекта:

```bash
bash tools/build_all.sh   # все версии → modrinth/files/
gradle build              # только линия 26.1.x → build/libs/translatebar-1.1.0.jar
```

Готовые имена файлов: `translatebar-1.1.0+26.1.jar` (покрывает 26.1–26.1.2),
`translatebar-1.1.0+26.2.jar`, `translatebar-1.1.0+26.3.jar`, `translatebar-1.1.0+1.21.11.jar`.
Версия мода намеренно зафиксирована на 1.1.0, чтобы заменять JAR без дублей в `mods`.

## Раскрытия

**Данные.** При нажатии на кнопку перевода текст из поля чата отправляется по HTTPS на публичный сервис перевода Google (`translate.googleapis.com`). Больше ничего не передаётся. Без нажатия кнопки сетевых запросов нет.

**ИИ.** Проект создан автором совместно с генеративными ИИ-инструментами (ChatGPT и OpenCode): все решения по продукту, дизайну и тестирование в игре — за автором; значительная часть кода написана с помощью ИИ.
