# TranslateBar

Крошечный клиентский Fabric-мод, который переводит всё, что вы пишете в чат Minecraft, — прямо в строке чата, не выходя из игры.

## Возможности

- **Две компактные кнопки прямо в строке ввода чата.** `文` переводит, чип с кодом языка (`EN`, `DE`, …) переключает язык перевода.
- **Любой исходный язык.** Исходный язык определяется автоматически — печатайте на русском, английском, японском, любом.
- **10 языков перевода:** EN, DE, FR, ES, PL, ZH, RU, JA, IT, PT.
- **Говорит на вашем языке.** Подсказки и сообщения — на русском или английском, в зависимости от языка игры.
- **Текст остаётся под вашим контролем.** Перевод подставляется в поле ввода; проверьте его и нажмите Enter сами. Команды, начинающиеся с `/`, не переводятся.
- **Без настройки.** Никаких API-ключей и конфигов.
- **Игра не зависает.** Запросы на перевод выполняются в фоне.
- **Подстраивается под ваш чат.** Кнопки совпадают по высоте с полосой чата и следуют настройке прозрачности фона текста в игре.

## Поддерживаемые версии

Выберите файл под свою версию игры:

- **26.1, 26.1.1, 26.1.2** — `translatebar-1.1.0+26.1.jar`
- **26.2** — `translatebar-1.1.0+26.2.jar`
- **26.3** — `translatebar-1.1.0+26.3.jar`
- **1.21.11** — `translatebar-1.1.0+1.21.11.jar`

## Требования

- **Fabric Loader 0.19.5+** и **Fabric API** под вашу версию игры.
- **Java 25** для сборок 26.x, **Java 21** для сборки 1.21.11 — лаунчеры обычно ставят её сами.

## Как пользоваться

1. Положите Fabric API и подходящий файл TranslateBar в папку `mods`.
2. Откройте чат (`T`) и наберите сообщение.
3. Нажмите `文` — текст в поле заменится переводом.
4. Нажимайте чип языка, чтобы переключать язык перевода. Выбор сохраняется до закрытия игры.

## Сборка из исходников

Из одного Gradle-проекта собираются все линии игры (нужны JDK 25 и Gradle):

```bash
bash tools/build_all.sh   # все версии → modrinth/files/
gradle build              # только линия 26.1.x
```

## Раскрытия

**Данные и приватность.** При нажатии кнопки перевода текст из поля чата отправляется по HTTPS на публичный сервис перевода Google (`translate.googleapis.com`). Больше ничего не передаётся — ни аккаунт, ни история чата, ни телеметрия. Если кнопку не нажимать, сетевых запросов нет.

**ИИ-контент.** Проект создан автором совместно с генеративными ИИ-инструментами (ChatGPT и OpenCode). Все решения по продукту, дизайну и тестирование в игре выполнены автором; значительная часть кода написана с помощью ИИ.
